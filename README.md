Скрипт заменяет ссылки на изображения в markdown файлах на локальные файлы

> [!CAUTION]
> Сначала протестируйте на копии файлов

Сканирует все файлы в текущей папке с расширением .md<br>
Находит ссылки на изображения<br>
Скачивает изображение<br>
Заменяет URL на путь к скачанным файлам в markdown файле<br>
Копирует файлы изображений и новый markdown папку output<br>

Изначально создан для замены ссылок на локальные файлы при добавлении заметок в Obsidian
